Chrome Extension

FCR AIL

One click registers your dialer numbers with the Free Caller Registry. Fills the whole form, walks the wizard, and stops only for the emailed verification code.

Download extension
v2.1.0 · Chrome, Edge, Brave

Install

  1. Unzip the download. You'll get a folder named fcr-extension. Put it somewhere permanent — Documents, not Downloads. Chrome reads from this folder every time it starts, so moving or deleting it breaks the extension.
  2. Open chrome://extensions — paste that into the address bar.
  3. Turn on Developer mode using the toggle in the top-right corner.
  4. Click "Load unpacked" and select the fcr-extension folder. Pick the folder that has manifest.json directly inside it.
  5. Pin it. Click the puzzle-piece icon in the toolbar, then the pin next to FCR AIL.
Windows note: extracting sometimes creates fcr-extension\fcr-extension. If Chrome says the manifest is missing, you selected the outer folder — pick the inner one.

First run

A setup page opens automatically. Enter your name, your email, and the phone numbers you're registering — use + Add another number for more than one, up to 20. Company details are pre-filled with AIL's. Save once and you're done.

Every run after

  • Click the FCR AIL icon in your toolbar.
  • The registry opens, fills itself, and requests your verification code.
  • Your cursor lands in the code box — type the 5 digits from your email.
  • It finishes the remaining steps and shows your Feedback ID.

Before you register

The registry requires that you are the business that uses these numbers, and that you're authorized to submit on its behalf. Confirm with your agency how agent numbers should be registered before submitting — carriers can invalidate registrations later if that authorization doesn't hold up.
Questions or a number that won't register — reach out before re-submitting. Duplicate submissions of the same number add nothing.
