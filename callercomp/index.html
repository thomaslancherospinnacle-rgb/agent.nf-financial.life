Persistency Factor
Auto-calculated from the Status column — rolling 12-month window. Set rows to GOOD or CHARGEBACK in Sheets. Bonus unlocks after 10+ policies total in the window.
How it works
advance = (monthly × 12) × 0.60 × 0.65
base = advance × role% (setter 15%, closer 25%)
persistency% = GOOD rows ÷ total rows (this month)
bonus = hockey stick 0–10% (requires 10+ policies)
owed = base × (1 + bonus%)

Base pay is always fixed. The persistency bonus adds on top. Bonus unlocks only after 10 policies are sold in the month — then scales from +0% at 70% persistency up to +10% at 100%.

Setup Instructions
  1. Open Google Sheet → Extensions → Apps Script
  2. Paste AIL_CompTracker_GAS.js → Save
  3. Run setupSheet() once — creates the Sales tab with headers + totals row
  4. Deploy → New Deployment → Web App

  5. Copy the URL and paste it above → Save & Connect
  6. App auto-loads from Sheet on every open — edit rows directly in Sheets anytime
